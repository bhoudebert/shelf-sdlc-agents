Reference and honesty

Configuration lists every file and key. Security model says what the system guarantees. Architecture says how it is built. Limits says what is weak or unverified: read it before you point Shelf at a repository you care about.

Shelf is open source under the Apache-2.0 licence and in early development. What it does not do yet is written down, not hidden.

Read the limits before you point it at a repository you care about.
