The GitHub App

One app does sign-in, repository access and the agents' identity.

Early development. The registration flow below is built and tested against GitHub's documented API. It has not been exercised against a live GitHub account yet.

Registration by manifest

Instead of filling in a long form, the web service offers a GitHub App manifest flow on its first page while no App is configured. You press one button, GitHub shows the app's proposed name and settings, you confirm, and GitHub returns the app id, client id, client secret, webhook secret and private key for you to place in .env.

Repository permissions

PermissionAccess
ContentsRead and write
Pull requestsRead and write
IssuesRead and write
ChecksRead
MetadataRead

Webhook events

  • pull_request
  • issue_comment
  • check_suite
  • installation
  • installation_repositories
  • push

Webhooks are used in server mode. In local mode the app is polled instead.

Granting repositories

Install the app on your account or organisation and choose which repositories it may touch. Only repositories you grant appear in the picker, and the app can never reach the others.

Creating it by hand

The one-click registration fills all of this in for you. If you prefer the form on GitHub (Settings, Developer settings, GitHub Apps, New GitHub App), use these values, with your own address in place of https://shelf.example.org:

FieldValue
Homepage URLhttps://shelf.example.org
Callback URLhttps://shelf.example.org/auth/callback: where GitHub sends people back after they sign in.
Request user authorization during installationLeave unchecked.
Setup URL (optional)https://shelf.example.org/setup/installed: where people land after installing the App. Tick "Redirect on update".
Webhook: ActiveChecked.
Webhook URLhttps://shelf.example.org/api/github/webhook
Webhook secretA long random string that you make up, for example openssl rand -hex 32. Put the same value in GITHUB_WEBHOOK_SECRET. GitHub uses it to sign every delivery and the instance refuses any delivery that is not signed with it.
Where can this App be installed?Only on this account.

Then set the repository permissions and events listed above. After creating the App, generate a client secret and a private key on its page and fill GITHUB_APP_ID, GITHUB_APP_SLUG (the name in the App's URL), GITHUB_APP_CLIENT_ID, GITHUB_APP_CLIENT_SECRET, GITHUB_WEBHOOK_SECRET and GITHUB_APP_PRIVATE_KEY in deploy/.env.
