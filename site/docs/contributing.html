Contributing

Help is welcome at every stage of this early project.

People and coding agents follow the same path from a need to a release: decision records for architectural choices, specs for behaviour changes, Conventional Commits, and required checks on every pull request.

The full guide is in the repository: CONTRIBUTING.md. The short rules for coding agents are in AGENTS.md.

What helps most

  1. A bug report with the steps to reproduce it.
  2. A fix or a feature that follows the path in the guide.
  3. Documentation and examples.
