Architecture

Hexagonal layers around a pure functional core.

Layers

LayerHolds
domainThe work-item state machine and access rules. Pure, with no I/O.
portsThe interfaces the application needs from the outside world.
applicationUse cases that orchestrate the domain through ports.
adaptersImplementations of the ports: Temporal, the GitHub App, git, the Claude Agent SDK, configuration files and the web interface.
entrypointsThe web app, the worker and webhook handlers that start everything.

Dependencies point inward only. The domain knows nothing about Temporal, GitHub or the web. The repository enforces this with an import linter in CI.

The pure decider, the thin workflow

All the rules live in one function:

decide(state, event) -> (state, commands)

Given the current state and an event (a person decided, a check finished, a round ended), it returns the next state and a list of commands for the outside world. The Temporal workflow does nothing clever: it receives events, calls decide, and carries out the commands. Because the function is pure it is tested with property-based tests, and the workflow stays small enough to read in one sitting.

Stack

Python 3.13, strict typing, Temporal for durability, the Claude Agent SDK for agents, property-based tests, Apache-2.0. See the decision records for the reasons behind these choices.
