Getting started

Self-host shelf-sdlc with one Docker Compose file.

Planned interface. This describes where the project is heading. The deployment and several components below are still being built, and names may change before release.

What you will run

The compose file starts three services: Temporal (durable workflows), web (sign-in, UI, webhooks) and worker (runs the workflows and the agents). There is no bundled reverse proxy. Terminate TLS with a proxy you already have, or a Kubernetes ingress, and point it at the web service.

Steps

  1. Register the GitHub App from the manifest and keep its private key.
  2. Write shelf.toml to say which organisations and users may sign in and who administers the instance (see Configuration).
  3. Create an .env file with the variables below.
  4. Start the stack.

Environment variables

VariablePurpose
GITHUB_APP_IDNumeric id of your GitHub App.
GITHUB_APP_PRIVATE_KEY_PATHPath to the app's private key (PEM), mounted into the containers.
GITHUB_APP_CLIENT_IDOAuth client id of the app, used for sign-in.
GITHUB_APP_CLIENT_SECRETOAuth client secret of the app.
GITHUB_WEBHOOK_SECRETSecret used to verify webhook deliveries (server mode).
SESSION_SECRETRandom secret that signs web sessions.
PUBLIC_URLThe public address of the instance, used for callbacks and webhooks.
MODElocal or server. See below.
ANTHROPIC_API_KEYModel credentials: an API key...
CLAUDE_CODE_OAUTH_TOKEN...or a Claude Code OAuth token.
ANTHROPIC_BASE_URLOptional: send model calls through another endpoint.

Provide one of ANTHROPIC_API_KEY or CLAUDE_CODE_OAUTH_TOKEN.

Local and server mode

  • local: for a machine that GitHub cannot reach. The workflow polls GitHub on a durable timer whose interval slows down while nothing changes.
  • server: webhooks wake the work as soon as something happens. Polling remains as a safety net in case a delivery is lost.

Start it

cp .env.example .env      # fill in the variables above
docker compose up -d

Then open PUBLIC_URL, sign in with GitHub, and choose a repository the app can access.
