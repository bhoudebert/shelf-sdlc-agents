Connect this instance to GitHub

One click registers a GitHub App that signs people in, lets them pick repositories and gives the agents their own identity.

Registering for {{ public_url }}

Register on GitHub

GitHub shows you the name and permissions first. Nothing is created until you confirm there.

  1. Confirm on GitHub. You come straight back to this page.
  2. Copy the credentials. They are shown once. Paste them into deploy/.env and run sh deploy/install.sh again.
  3. Install the App on the repositories you want to use, then sign in.

Repository permissions
Contents: read and write. Pull requests: read and write. Issues: read and write. Checks: read-only. Metadata: read-only.
Subscribe to events

Where can this App be installed?
Only on this account

After creating it, generate a client secret and a private key on the App's page, then fill GITHUB_APP_ID, GITHUB_APP_SLUG (the name in its URL), GITHUB_APP_CLIENT_ID, GITHUB_APP_CLIENT_SECRET, GITHUB_WEBHOOK_SECRET and GITHUB_APP_PRIVATE_KEY in deploy/.env.

What the App is allowed to do

  • Contentsread and write: push the agents' branches
  • Pull requestsread and write: open them, review, comment
  • Issuesread and write: comments on pull requests
  • Checksread: see your project's results
  • Metadataread: required by GitHub

Private to your account. Access is limited to the repositories you install it on, and the agents only receive a token that lasts one hour.
