One click registers a GitHub App that signs people in, lets them pick repositories and gives the agents their own identity.

Register on GitHub

GitHub shows you the name and permissions first. Nothing is created until you confirm there.

  1. Confirm on GitHub. You come straight back to this page.
  2. Copy the credentials. They are shown once. Paste them into deploy/.env and run sh deploy/install.sh again.
  3. Install the App on the repositories you want to use, then sign in.
Or create the App by hand, step by step

Use this if the button above did not work, or you prefer to see every field. Five steps, about five minutes.

1. Create the App on GitHub

Open github.com/settings/apps/new (opens in a new tab) (Settings, Developer settings, GitHub Apps, New GitHub App) and fill in:

GitHub App name
anything unique, for example shelf-sdlc-yourname. It becomes your slug.
Homepage URL
{{ public_url }}
Callback URL
{{ public_url }}/auth/callback where GitHub sends people back after they sign in
Request user authorization (OAuth) during installation
leave unchecked
Setup URL (optional)
{{ public_url }}/setup/installed where people land after installing the App. Also tick "Redirect on update".
Webhook: Active
checked
Webhook URL
{{ public_url }}/api/github/webhook
Webhook secret
a long random string that you make up, for example the output of openssl rand -hex 32. Write it down: it becomes GITHUB_WEBHOOK_SECRET.
Repository permissions
Contents: Read and write. Pull requests: Read and write. Issues: Read and write. Checks: Read-only. Actions: Read-only (so the agents can read why a CI job failed). Metadata: Read-only. Everything else: No access.
Subscribe to events
Pull request and Issue comment, nothing else. Boxes stay greyed until the permissions above are set; tick only these two.
Where can this App be installed?
Only on this account

Click Create GitHub App. GitHub says "You must generate a private key in order to install your GitHub App": that is the next step, not an error.

2. Generate a client secret and a private key

You are now on the App's settings page. Scroll down:

  • Client secrets, Generate a new client secret. Copy it now: GitHub shows it only once.
  • Private keys, Generate a private key. Your browser downloads a .pem file once. Keep it.

3. Collect the values

Put each in deploy/.env on your server:

VariableWhere it comes from
GITHUB_APP_IDTop of the App's settings page: App ID, a number.
GITHUB_APP_CLIENT_IDJust under it: Client ID, starts with Iv. Not the App ID.
GITHUB_APP_SLUGThe name in the App's public link, github.com/apps/slug: the App name in lowercase, spaces as hyphens.
GITHUB_APP_CLIENT_SECRETThe client secret you generated in step 2.
GITHUB_WEBHOOK_SECRETThe string you made up in step 1. Same value, exactly.
the private keyNot in .env: the .pem file itself. Step 4.

4. Put the private key on the server

Copy the .pem you downloaded to deploy/secrets/github-app.pem in your checkout. It is a file, not a line in .env, so there is nothing to paste or escape.

scp ~/Downloads/*.pem you@server:~/shelf-sdlc-agents/deploy/secrets/github-app.pem

On most servers your user is uid 1000 and chmod 600 on the file is enough. If the service says it cannot read the key, run chmod 644 on it: the directory is private to you.

5. Restart

Add the five variables (and a model key, ANTHROPIC_API_KEY) to deploy/.env, then run sh deploy/install.sh on the server. If something is missing, the log names it and says where to find it: docker compose -f deploy/compose.yml logs web.

What the App is allowed to do

  • Contentsread and write: push the agents' branches
  • Pull requestsread and write: open them, review, comment
  • Issuesread and write: comments on pull requests
  • Checksread: see your project's results
  • Metadataread: required by GitHub

Workflows is left off on purpose: it would let agents change CI files, which run with your repository's secrets. Turn it on later only if you want that.

Private to your account. Access is limited to the repositories you install it on, and the agents only receive a token that lasts one hour.
