How much may this run do without you?

Fewer stops mean more autonomy, less control and potentially less quality. The pull request is never merged without you, and the code review and the repository's checks always run. The boxes show this repository's defaults: change them for this work only.

Less control. Nobody will be asked at the stops you removed, so the spec or design can reach the pull request with open points or unchecked assumptions. Read them on the pull request before you merge.
