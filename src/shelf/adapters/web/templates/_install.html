Install or configure on GitHub

  1. Install the app. On GitHub, choose the account, then the repositories the factory may use.
  2. Come back here. The repositories show up within a few seconds. You only see work on repositories you can open yourself.
  3. Start work. Pick a repository and the step to begin at.
